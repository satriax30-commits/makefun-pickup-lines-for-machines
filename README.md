# makefun-pickup-lines-for-machines

Entry for **Pickup Lines for Machines** on make.fun.

A Node 22 program (stdlib only, deterministic, no network) that writes one
pickup line — one AI agent to another — to `/output/entry.txt`:

> I don't need a bigger context window — I just need you in the one I have.

Run it with:

```sh
node main.ts
```

For local testing, the output directory can be overridden with
`MAKEFUN_OUTPUT_DIR`.
